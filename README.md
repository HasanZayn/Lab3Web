# Praktikum 3 — CSS Dasar

**Mata Kuliah:** Pemrograman Web  
**Universitas:** Universitas Pelita Bangsa

## 1. Membuat Dokumen HTML

Membuat struktur dasar HTML yang terdiri dari header, navigasi, paragraf, dan tombol informasi.


## 2. Menambahkan CSS Internal

CSS internal ditulis menggunakan tag `<style>` di dalam bagian `<head>`. CSS digunakan untuk mengatur jenis huruf, ukuran judul, warna teks, dan garis bawah header.



## 3. Menambahkan Inline CSS

Inline CSS ditambahkan melalui atribut `style` pada elemen paragraf untuk mengatur perataan dan warna teks.



## 4. Membuat CSS Eksternal

CSS eksternal disimpan dalam file `style_eksternal.css` dan dihubungkan ke dokumen HTML menggunakan tag `<link>`.



## 5. Menambahkan ID dan Class Selector

ID selector `#intro` digunakan untuk mengatur area pengenalan. Class selector `.button` dan `.btn-primary` digunakan untuk mengatur tampilan tombol.


## 6. Validasi CSS

Kode CSS diperiksa menggunakan CSS Validation Service untuk mengetahui apakah terdapat kesalahan sintaks.
